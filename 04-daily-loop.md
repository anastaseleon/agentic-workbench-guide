# 4. The daily loop

| When | What you do |
|---|---|
| Morning, 5 min | Bring in captured items (see [guide 5](05-capture.md)), run `/triage`, then `/digest`. Read `today.md` and pick your top 3. |
| After a meeting or chat | Paste the recap or three lines (decided / I owe / they owe) into `inbox.md`, then `/triage`. |
| You need something from someone | `/ask` drafts the message. You send it yourself, then tell Copilot "sent" so it logs the ask. |
| Before a meeting | `/prep` |
| Someone wants a status | `/status` |
| Handing work to the cloud agent | `/delegate` writes the brief |
| Friday, 30 min | `/weekly`: clear stale items, draft the status, pick next week's 3 outcomes. |
| End of each session | Commit, then sync. |

## Habits

- **Check the branch** (bottom left of VS Code) before every prompt.
- **Read every terminal command** before you click Allow.
- **Wrong twice means a new rule.** If Copilot gets the same thing wrong twice, add a line to
  `.github/copilot-instructions.md`.
- **Overdue commitments first.** Do them or send a new date to whoever is waiting.

## After a week, then a month

Check whether you drop fewer follow-ups and start your mornings faster. If not, find what
gets in the way and simplify: fewer capture routes, fewer types, shorter digest.
